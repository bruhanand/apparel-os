## What this folder is

- One workbook, `ERP_DASHBOARD_V1.xlsx`: role-access tables for a first ERP scope, and a short dashboard requirement.
- **It was made by the ERP team, not by KDPS.** The file was generated by a script (author field "openpyxl", a Python library), created on 17 Jul 2026 (05:59 UTC) and last saved on 24 Jul 2026 (09:39 UTC). The folder copy is dated 3 Aug 2026. Its notes speak of a "locked decision" and "maker-checker rulings"; those are decisions of the earlier product's design, not KDPS decisions and not Apparel OS decisions (inferred from the wording; no KDPS record is attached).
- **Its roles are not the PRD personas.** The file uses six roles (`Owner`, `Store POS` or `Store Person`, `Warehouse`, `Brand Manager`, `Accounts`, `Admin`). The PRD has 14 personas (`P-OWN` to `P-AUD`, in [prd.md](../../prd.md), "People, access and approvals"), and `PRD-ACS-002` says a persona grants no access: only role assignments do. This file grants rights to roles directly.
- Treat every cell as an analyst's draft. Nothing here is signed by KDPS (OPEN: KDPS Owner).
